# KeyVault v1.3.0 Release Notes

## 🎉 What's New

### 🔍 License Sorting & Filtering
- **New sorting options**: Sort licenses by name (A-Z, Z-A), date added, or date modified
- **Intuitive filter UI**: Dedicated filter button with dropdown menu
- **Persistent timestamps**: Automatic tracking of creation and modification dates

### 🌐 Localization
- **Dual language support**: Full Korean and English translations for filter options
- **Auto-switching**: Language changes instantly across the entire app

### ✨ UI/UX Improvements
- **Refined filter button**: Merged design with hover glow effects
- **Smaller action buttons**: Streamlined Edit and Delete buttons for cleaner interface
- **Optimized typography**: Adjusted font sizes for better visual hierarchy
- **Button glow effects**: Added subtle glow on hover for Add License and Filter buttons

### 🐛 Bug Fixes
- **Icon display**: Fixed missing app icon in sidebar
- **Version sync**: App info now correctly displays v1.3.0
- **Auto-cleanup**: Automatically removes `.app` extension when dragging app files

### 🎨 Visual Enhancements
- **Updated app icon**: Fresh icon design pulled from latest assets
- **Consistent styling**: Improved dark mode compatibility

## 📦 Installation

Download the appropriate file for your system:
- **macOS (Apple Silicon)**: `KeyVault-1.3.0-arm64.dmg`
- **macOS (Zip)**: `KeyVault-1.3.0-arm64-mac.zip`

## 🔄 Upgrade Notes

This is a minor version update. Your existing data will be preserved when upgrading from v1.2.0.
